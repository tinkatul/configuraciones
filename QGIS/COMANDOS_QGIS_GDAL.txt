Para saber la proyección de una imagen TIF, en OSGeo4W Shell

(es un tipo cmd, Me acordaba que tenías QGIS instalado, pero el detalle era ese:

gdalinfo hay que ejecutarlo desde el OSGeo4W Shell (o QGIS Command Prompt), porque ese entorno ya tiene configuradas las variables de entorno (PATH) para encontrar todas las herramientas de GDAL.)

gdalinfo CURVAS_BDCH.tif

y devuelve algo como: (VER ABAJO)


Un dato útil para GDAL

Además de gdalinfo, desde el OSGeo4W Shell vas a tener disponibles muchas herramientas muy útiles:

ogrinfo → inspeccionar capas vectoriales.
ogr2ogr → convertir y reproyectar Shapefile, KML, GeoPackage, etc.
gdal_translate → convertir y recortar rasters.
gdalwarp → reproyectar rasters.
gdaldem → generar sombreado, pendientes, orientación, etc.
gdal_contour → generar curvas de nivel desde un DEM.
